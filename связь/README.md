# связь/ — реестр шаблонов и управление ботом

Сервис-оркестратор: читает `шаблоны/*/template.json`, показывает список шаблонов и их env-требования, помогает управлять ботом.

- `registry.ts` — чтение манифестов шаблонов.

Правила: не импортирует код из `главная`, `шаблоны`, `телеграмм-бот`; читает единый корневой `.env`.
