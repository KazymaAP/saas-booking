# ТЗ: редизайн интерфейса saas-booking

Дата: 2026-10. Статус: черновик на утверждение.

## 1. Цель

Интерфейс должен выглядеть как продукт для малого бизнеса: понятно, спокойно, без лишних элементов. Сейчас панели функциональны, но выглядят как черновик. Редизайн не меняет логику и данные.

## 2. Что входит

| Зона | Экраны | Приоритет |
|---|---|---|
| Сайт клиента | Главная, блок записи, услуги, карта, футер | 1 |
| Кабинет владельца | Вход, главная, брони, услуги, фото, настройки, тексты | 1 |
| Супер-админка | Вход, воронка, бизнесы, клиенты, шаблоны, статистика | 2 |
| Служебные | /privacy, /oferta, /blocked, 404, ошибки | 3 |

Сайт клиента уже оформлен по эталону `rabota` (`public/assets/studio.css`). Его не переделываем, только доводим до единого стиля с панелями.

## 3. Аудитория

- **Клиент бизнеса** (владелец студии, мастер): открывает телефон, хочет быстро посмотреть записи и подтвердить их.
- **Клиент сервиса** (клиент студии): записывается с телефона за 3–4 касания.
- **Оператор** (вы): работает с воронкой и таблицами на ноутбуке, много данных.

## 4. Принципы

1. **Спокойствие.** Один акцентный цвет, много воздуха, минимум рамок.
2. **Один главный action на экран.** Остальные кнопки вторичные.
3. **Таблица — только там, где нужно сравнивать.** Брони на телефоне — карточками.
4. **Состояния всегда видны:** загрузка, пусто, ошибка, успех.
5. **Текст понятный, без жаргона.** Не «Генерировать прототип», а «Создать демо-сайт».

## 5. Визуальная система

- **Шрифт:** Inter (уже в `public/assets`), кириллица.
- **Цвета:** нейтральные: `#111` текст, `#6b6b6b` вторичный, `#e5e5e5` линии, `#fafafa` фон. Акцент берётся из `brand_color` бизнеса, по умолчанию `#111`.
- **Статусы:** зелёный `#16a34a`, красный `#dc2626`, жёлтый `#ca8a04`, серый. Только в виде точки или бейджа.
- **Шкала отступов:** 4, 8, 12, 16, 24, 32.
- **Радиусы:** 8 для полей и кнопок, 12 для карточек.
- **Тени:** не использовать, кроме выпадающих меню.

## 6. Компоненты

Минимальный набор, все в одном месте (`components/ui`):

> Состояние на 2026-10-16: папки `components/ui` ещё нет. Сейчас стили панелей — классы `.panel-shell`, `.btn-primary`,
> `.input` в `app/globals.css`. Папка создаётся в рамках редизайна.

- Кнопка: первичная, вторичная, текстовая, опасная. Высота 40 (44 на телефоне).
- Поле ввода с подписью, подсказкой и текстом ошибки.
- Карточка и секция с заголовком.
- Таблица: заголовок серым, строки с hover, пустое состояние.
- Бейдж статуса.
- Тост для результата действия.
- Модальное окно подтверждения для опасных действий (удаление, отмена).
- Пустое состояние: иконка, одна фраза, одна кнопка.
- Скелетон загрузки.

## 7. Экраны: требования

### 7.1. Вход (кабинет и супер-админка)
- Один блок по центру, логотип, два поля, одна кнопка.
- Ошибка под полем, не общим текстом.

### 7.2. Главная кабинета
- Сверху: приветствие и название студии.
- Два крупных числа: записи сегодня и на 7 дней.
- Чек-лист готовности сайта (4 пункта, прогресс-бар).

### 7.3. Брони
- Переключатель: предстоящие / все за 30 дней.
- На телефоне — карточки, на десктопе — таблица.
- Кнопки действий: подтвердить (главная), выполнено, не пришёл, отменить (вторичные).

### 7.4. Услуги, фото, тексты, настройки
- Форма в одну колонку, максимум 560 px.
- Сохранение с тостом. Несохранённые изменения предупреждаются при уходе.

### 7.5. Воронка (супер-админка)
- Пять шагов вертикально, номер шага и статус сверху.
- Прогресс генерации виден.
- Предпросмотр письма в рамке, как в почтовом клиенте.

### 7.6. Сайт клиента
- Без изменений структуры. Проверить контраст текста и кнопок (WCAG AA).
- Кнопка записи всегда видна на телефоне (нижняя панель или закреплённая кнопка).

## 8. Адаптивность

- Точки: 375, 768, 1280 px.
- На телефоне боковая навигация превращается в нижнюю панель из 3–4 пунктов.
- Таблицы на телефоне — карточки или горизонтальный скролл, без поломки верстки.

## 9. Доступность

- Контраст текста не ниже 4.5:1.
- Все поля с подписями, ошибки связаны с полями (`aria-describedby`).
- Видимый фокус с клавиатуры.
- Цвет не единственный признак статуса: есть текст или иконка.

## 10. Что не делаем

- Анимации дольше 200 мс и декоративные эффекты в панелях.
- Тёмная тема (в MVP).
- Новые шрифты сверх Inter.
- Изменение логики, данных и маршрутов.
