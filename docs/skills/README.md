# Навыки (скиллы), которые использовались в проекте

Здесь лежат копии навыков агента, чтобы они не потерялись при переустановке системы.
Рабочие версии живут в домашней папке агента и подключаются оттуда.

## slopotron — «Слопотрон»

- **Что делает:** находит и убирает в русском тексте AI-маркеры, канцелярит, мёртвые клише
  и «нейротропы» — то, что выдаёт нейросеть.
- **Режимы:** Fix (находит и правит) и Detect (только список флагов, без переписывания).
- **Когда применять:** любой текст, который увидит человек — лендинг, оферта, письмо,
  сообщение об ошибке, описание тарифа, коммит, документация.
- **Главное правило:** сигнал даёт **кластер из 3+ маркеров в одном абзаце**, а не одиночное
  совпадение. Одиночное тире, параллелизм или слово «экосистема» — не приговор.
  Запрещено стерилизовать живой текст: правится связка, смысл и интонация автора сохраняются.
- **Источник:** https://github.com/beaverbeard/slopotron (MIT), папка `.claude/skills/slopotron`.
- **Установка заново:**

```powershell
git clone --depth 1 https://github.com/beaverbeard/slopotron.git $env:TEMP\slopotron-src
Copy-Item "$env:TEMP\slopotron-src\.claude\skills\slopotron" "$env:USERPROFILE\.workbuddy-ai\skills\slopotron" -Recurse -Force
```

Проверить, что навык виден, можно через каталог навыков агента (имя `slopotron`).
Копия в этом репозитории — на случай, если репозиторий-источник исчезнет.

## ECC — инженерный цикл (в репозиторий не копируется)

- 25 навыков `ecc-*` в `~/.workbuddy-ai/skills/`, вход — `ecc-workflow` (там карта).
- 13 агентов в `<workspace>/.codebuddy/agents/`.
- Полный клон: `C:/Users/rrrme/AppData/Local/Temp/ECC` (328 навыков, 72 агента).
- Источник: https://github.com/affaan-m/ECC

**Почему не в репозитории:** это мегабайты чужих навыков под чужие стеки; в git они
раздувают клон и мешают ревью. Ставятся одной командой, если понадобятся.

**Не ставить** `hooks-runtime` ECC: он правит файлы проекта, переписывает команды,
отправляет текст переписки во внешнюю LLM и может блокировать Edit/Write/Bash.
Только с `--no-hooks`. Полный набор из 328 навыков тоже не нужен — 90 % про другие стеки.
