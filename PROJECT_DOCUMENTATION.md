## Краткая сводка

**Что это.** Мультитенантная SaaS-платформа готовых сайтов с онлайн-записью для малого бизнеса. Один Next.js 14 проект и одна база Supabase обслуживают все бизнесы. Каждый бизнес — строка в `businesses` со своим публичным сайтом `/{prefix}/{slug}`, кабинетом владельца `/{prefix}/{slug}/panel`, услугами, фотографиями, бронями и (опционально) собственным доменом.

**Две задачи платформы** (`README.md`): продажа (оператор импортирует выгрузку 2GIS, генерирует прототипы, рассылает письма, ведёт по воронке до оплаты) и работа клиента (после оплаты — публичный сайт, онлайн-запись, кабинет, уведомления в Telegram и на email).

**Зона ответственности владельца платформы** — работоспособность самой платформы: аптайм, биллинг/подписки, модерация, поддержка, шаблоны, интеграции, безопасность, аудит. Операционка конкретных арендаторов (их клиенты, записи, услуги) — вторична; супер-админка не предназначена для ручного управления чужими бизнесами.

**Роли.**

| Роль | Где работает | Как логинится | Что может |
|---|---|---|---|
| Супер-админ | `/panel/*`, `/admin` | `/panel/login`, email+пароль, `SUPERADMIN_EMAILS` + Supabase Auth | Воронка, бизнесы, рассылки, лицензии, настройки, бэкап, статистика |
| Владелец бизнеса | `/{prefix}/{slug}/panel` | `/auth` или `/{prefix}/{slug}/panel/login` | Все разделы кабинета, включая настройки, подписку, команду, данные |
| Менеджер бизнеса | `/{prefix}/{slug}/panel` | Там же | Брони, услуги, фото, тексты, уведомления; без настроек/подписки/команды/данных |
| Партнёр | `/partner` | `/auth` (своя таблица `partners`, scrypt + HMAC-cookie) | Лиды, счета, начисления, готовые сервисы, рефералка |
| Клиент бизнеса | `/{prefix}/{slug}` или кастомный домен | Без регистрации | Онлайн-запись, отмена/перенос по токену |

**Стек:** Next.js 14.2.15 App Router, React 18.3.1, TypeScript 5.6.2, Tailwind CSS 3.4.13 (без shadcn, preflight отключён), Supabase JS 2.45.4 (Postgres + Auth + Storage), react-hook-form 7.53.0 + zod 3.23.8, nodemailer 6.9.15 + imapflow 1.0.164, @phosphor-icons/react 2.1.10, Leaflet 1.9.4, xlsx 0.18.5, archiver 7.0.1, sanitize-html 2.13.1, pino 9.4.0. Тесты: Vitest 2.1.9 (unit), Playwright 1.48.2 (e2e). Пакетный менеджер pnpm. Хостинг Vercel (`regions: ["lhr1"]`) + Supabase. `package.json → engines.node: "22.x"`.

**Масштаб кода (фактические счётчики):** `app/` — 315 файлов; `общие/lib/` — 180; корневой `lib/` — 174; `главная/` — 23; `шаблоны/` — 36; `components/` — 12; `scripts/` — 19; `tests/` — 41; `supabase/migrations/` — 20 SQL-файлов; `служебное/docs/` — 20; `public/` — 3769 файлов; `.ts/.tsx` всего по проекту — 1321; unit-тестов — 155 файлов; MD-документов в верхних двух уровнях — 20.

**База:** 20 миграций `0001_init.sql` … `0020_partner_referrals.sql`. Таблицы создаются в 0001 (21 таблица), 0006/0011/0014 (партиционированные служебные), 0007 (ещё 20+), 0017 (партнёрская программа), 0018 (готовые сервисы), 0020 (второй уровень рефералки). RLS включён на всех таблицах, `service_role` обходит RLS и используется серверным кодом. Расширения: `pgcrypto`, `btree_gist`, `pg_cron`, `pg_net`. Storage buckets: `backups` (приватный), `photos`, `logos` (публичные).

**Ключевые подсистемы:** бронирование (слоты на лету, уникальный индекс против двойной брони, rate limit), воронка продаж (импорт 2GIS → прототипы → рассылка → оплата), почта (очередь `email_queue`, ротация ящиков, IMAP-входящие, трекинг открытий/кликов, отписка), Telegram (один бот на роли бизнеса и оператора), лицензии и передача кода, кастомные домены (middleware + подписанная cookie + Vercel API), партнёрская программа (лиды, счета, ЮKassa, начисления, двухуровневая рефералка, готовые сервисы из парсера), аналитика сайтов, JSON-бэкапы, PWA.

**Фоновые задачи:** единый реестр `общие/lib/schedules.ts` — 2 задачи Vercel Cron (лимит Hobby), 11 HTTP-задач pg_cron, 6 SQL-задач, плюс отдельные маршруты `send-emails`, `check-replies`. Все HTTP-задачи защищены `Authorization: Bearer CRON_SECRET`.

**Текущее состояние:** фундамент зелёный, все релиз-блокеры из `PROGRESS.md` закрыты в коде; миграции 0001–0020 накатывались на реальный Supabase через Management API. Проект задеплоен на Vercel, домен `zapishisya.ru` (reg.ru) через A-записи на `76.76.21.21`. Подробности и известные инфраструктурные нюансы — в томе 12.
