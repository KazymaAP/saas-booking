# tutor/ — шаблон репетитора / курсов

Ниша «Репетитор / курсы» (url-префикс `t`): школа, ЕГЭ/ОГЭ, языки, проф. направления.

- `theme.ts` — пресет `NicheTheme` (иконка `book`, «школа», инфо-карточки,
  поле «Предмет / уровень», ресурс «преподаватель»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
