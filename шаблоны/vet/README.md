# vet/ — шаблон ветеринарной клиники

Ниша «Ветеринарная клиника» (url-префикс `v`): приём, вакцинация, чипирование, хирургия.

- `theme.ts` — пресет `NicheTheme` (иконка `paw`, «клиника», инфо-карточки,
  поле «Питомец», ресурс «кабинет»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
