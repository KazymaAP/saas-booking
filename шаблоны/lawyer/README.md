# lawyer/ — шаблон юриста / адвоката

Ниша «Юрист / адвокат» (url-префикс `l`): консультации, договоры, суд, сделки.

- `theme.ts` — пресет `NicheTheme` (иконка `scales`, «бюро», инфо-карточки,
  поле «Суть вопроса», ресурс «кабинет»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
