# dentist/ — шаблон стоматологии

Ниша «Стоматология» (url-префикс `s`): терапия, гигиена, имплантация, ортодонтия.

- `theme.ts` — пресет `NicheTheme` (иконка `tooth`, «клиника», инфо-карточки,
  необязательное поле «Комментарий», ресурс «кабинет»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
