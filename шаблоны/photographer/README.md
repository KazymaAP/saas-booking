# photographer/ — шаблон фотостудии

Ниша «Фотостудия» (url-префикс `p`): портрет, семейная, предметная, рекламная съёмка.

- `theme.ts` — пресет `NicheTheme` (иконка `camera`, «студия», инфо-карточки,
  поле «Тип съёмки», ресурс «зал»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
