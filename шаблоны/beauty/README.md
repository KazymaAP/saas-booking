# beauty/ — шаблон салона красоты

Ниша «Салон красоты» (url-префикс `b`): стрижки, маникюр, брови, косметология.

- `theme.ts` — пресет `NicheTheme` (иконка `sparkle`, бизнес-существительное «салон»,
  инфо-карточки, необязательное поле «Пожелания», ресурс «мастер»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
