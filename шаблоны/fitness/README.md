# fitness/ — шаблон фитнес-клуба

Ниша «Фитнес-клуб» (url-префикс `f`): зал, групповые, персональные тренировки.

- `theme.ts` — пресет `NicheTheme` (иконка `dumbbell`, «клуб», инфо-карточки,
  необязательное поле «Пожелания», ресурс «зал»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
