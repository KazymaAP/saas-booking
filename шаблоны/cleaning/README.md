# cleaning/ — шаблон клининга

Ниша «Клининг» (url-префикс `c`): генеральная и поддерживающая уборка.

- `theme.ts` — пресет `NicheTheme` (иконка `broom`, «служба», инфо-карточки,
  поле «Объект / площадь», ресурс «бригада»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
