# repair/ — шаблон ремонта техники

Ниша «Ремонт техники» (url-префикс `r`): ноутбуки, смартфоны, бытовая техника.

- `theme.ts` — пресет `NicheTheme` (иконка `wrench`, «сервис», инфо-карточки,
  поле «Техника / неисправность», ресурс «мастер»).
- `template.json` — манифест.

Рендер и запись — общий движок `шаблоны/_shared/`.
